# Controle de Faltantes

Sistema desenvolvido para auxiliar no controle e acompanhamento de itens faltantes, permitindo uma gestão mais organizada e eficiente dos processos internos.

## 🚀 Funcionalidades

- Cadastro de itens faltantes
- Consulta de registros
- Organização das informações
- Interface simples e intuitiva
- Controle e acompanhamento de pendências

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de facilitar o gerenciamento de itens pendentes, proporcionando maior controle, organização e agilidade na identificação de faltantes.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram aplicados conceitos de:

- Estruturação de páginas com HTML
- Estilização com CSS
- Manipulação de elementos utilizando JavaScript
- Organização de código e boas práticas de desenvolvimento
